# 重绘准入与交付闸门

这份文件是硬规则，不是建议。目标：在出图前拦住“文字压图元、图元乱重叠、箭头断裂、示意图冒充忠实重绘”。

## 零、化学结构专用：RDKit 必须已加载

- 只要任务是**绘制/重绘有机结构或反应式**，先运行：

  ```text
  python scripts/canvas.py doctor --require rdkit
  ```

- 退出码非 0 → 停下，安装/激活隔离运行时；不得改用系统 Python、手写 SVG、matplotlib 或只凭 OCR 文本拼结构。
- 只允许通过 `python scripts/image_pipeline.py chemistry --smiles/--molfile` 生成；`canvas.py` 会自动切到 `.runtime`。
- 图片转结构必须先得到可核对的 SMILES/Molfile；MolScribe/DECIMER 包存在不等于权重已加载，真实推理未验证时不得宣称结构正确。
- 没有可用识别模型时：让用户提供 SMILES/Molfile，或退回原样/高清化，不猜结构。

## 一、准入：什么情况不许重绘

| 条件 | 处理 |
|---|---|
| 只有文字描述，没有源图/裁切 | 不重绘；请用户补图，或原样/高清化 |
| 当前模型不能查看图片，也没有结构/坐标 | 不重绘；不假装看过原图 |
| 低清、模糊、关键连接不可辨 | 原样/高清化；把疑点列出来，不猜补 |
| 没有时间做代表图确认 | 不进入批量重绘 |
| 不能执行碰撞/箭头/标注审计 | 不交付“精美重绘” |

**原样和高清化是合法结果。** 不能用“用户选了重绘”当作必须画出来的理由。

## 二、禁止的做法

- 仅凭题干文字**编造**机构、连杆、齿轮、流程节点；
- 手填 `text(x, y)` 放构件编号，再凭肉眼判断是否压线；
- 用“弧线 + 单独短线”拼箭头，拼接头或方向不连续；
- 把放大/锐化说成“重绘”；
- 把示意图、近似图说成“忠实还原”；
- 先批量生成，再让用户帮忙找错。

## 三、交付前审计清单

### 语义

- [ ] 构件数量、连接关系、固定件、主动件与原图一致；
- [ ] 箭头方向与题干主动件一致；
- [ ] 角度字母对应题目所问的角，锐角/钝角不混；
- [ ] 没有增加题干没有的构件、尺寸或标注。

### 碰撞

- [ ] 文字不压线段；
- [ ] 文字不压滑块、齿轮、矩形、圆、机架等**填充图元**；
- [ ] 文字之间不重叠；
- [ ] 图元之间没有无意义重叠；
- [ ] 文字包围盒离画布边 ≥ 安全边距。

### 箭头

- [ ] 箭杆连续，不是断裂短线；
- [ ] 箭头端点落在目标图元上；
- [ ] 箭头头完整、未被画布或图元裁切；
- [ ] 方向正确；弯曲箭头沿正确弧线。

### 标注

- [ ] 每个编号绑定到具体构件，不靠“离得近”猜；
- [ ] 标签在构件外侧、不压轮廓；
- [ ] 自动避让有位移上限，超限就回几何层重排；
- [ ] 手机宽度和缩略图仍能辨认。

## 四、代表图与批量

1. 先做**一张**最有代表性的图；
2. 交付：源图裁切、代表图、审计结果、剩余疑点；
3. 用户确认后再做同批；
4. 同批每张图分别审计，不能拿一张通过代表全部；
5. 任意一张失败 → 该图标“未完成”，不拖累已通过项，也不整批宣称完成。

## 五、失败时怎么办

- 先退回**原样/高清化**，保留可用内容；
- 或请用户补清晰源图/裁切/关键连接；
- 或只交付已确认的那几张；
- 不把未通过的图重新上传到卡片，不覆盖原图。

## 六、常见症状 → 根因

| 症状 | 根因 | 修法 |
|---|---|---|
| 编号压在滑块/齿轮上 | 只检查文字 vs 线段，没检查填充图元 | 图元注册 + 文字/图元碰撞 |
| 虚线角弧穿过构件 | 角弧独立画，没和构件端点绑定 | 角弧锚定到铰链/端点，检查穿越 |
| 箭头像断线 | 弧和箭头分两段画 | 一条连续路径 + 实心箭头 |
| 编号飘到空白处 | 手填坐标或避让无上限 | 锚定到构件，位移超限报错 |
| 图看起来像另一台机构 | 从文字自由生成，没有源图约束 | 只允许描图/场景图重建 |
| 缩小后糊成一团 | 只按大图检查 | 手机宽度/缩略图三档验收 |

## 七、给用户的交付话术

```text
这张图我按“精美重绘”处理，但源图这个连接看不清；
我先给你原图/高清版 + 已完成的另一张，不猜这一张。
```

不要为了交付数量，把不确定的图说成已完成。
