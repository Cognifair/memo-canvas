# 流程图：关系先行，样式后置

在用户选择精美重绘后使用；不把传统高清化改成重绘。

## 从图片到结构

有多模态能力时查看原图，提取节点清单（稳定 ID、原文、形状、分组）和有向边清单（起点 ID、终点 ID、分支文字、箭头方向）。纯文本模型需要用户提供结构或外部识图结果。普通 OCR 仅提取文字不证明识别了连接关系。

反向箭头、回路、跨泳道连线与“是/否”均须记录；无箭头的连接不擅自变有向。跨线不能自动当连接点。看不清的箭头或文字先标疑点，不用业务常识补猜。

## 结构到图形

- 需要贴近原图、精细调整时，生成真实节点、文字、路径和箭头组成的 SVG。
- Mermaid/Graphviz 已安装时，可用于简单关系图的自动布局；不能默认安装或宣称已运行。用户要求泳道或特殊形状而工具表达不全时采用 SVG，不丢信息适配工具。
- HTML 负责外围说明与尺寸。SVG/HTML 不允许输入中的脚本、外链或命令执行；转义标签文字，禁用网络与页面脚本进行截图。
- 可改善节点间距、断行、统一尺寸与颜色、减少交叉；布局调整不能改变边的起终点和分支标签。颜色若在原图有含义，保留对应关系，不擅自把普通节点标为警告。

## 润色和核验

先做代表图。渲染后逐条核对节点文字和形状、每条边的起终点、箭头、条件、回路和分组。再检查文字溢出、线穿文字、箭头被遮挡、交叉歧义、图形裁切与卡片尺寸下的可读性。布局修改前后沿用同一份节点/边清单；清单不变只证明没有改动已提取关系，不证明提取与原图一致。

交付 PNG（实际可渲染时）、SVG 或 Mermaid/DOT 等编辑源，以及必要的结构清单和疑点。最多两轮针对性视觉调整，仍有问题就作为草稿说明，不伪称验收通过。
