# 函数图标注方案

用于 `mathplot` 和人工绘制的静态函数图。目标不是“标得越多越专业”，而是**只在有信息价值时加少量标注**。

## 默认

没有用户明确要求时：

```text
只画坐标轴
只画用户点名的标签
不自动加零点、极值、渐近线、周期、振幅
不自动加整排刻度数字
```

如果函数没有任何值得单独说明的边界或特殊值，**保持空标注**。

## AI 先判断

生成前先看表达式和可视范围，只考虑这几类候选：

1. **定义域边界**
   - 分段点；
   - 开区间端点；
   - 无定义点；
   - 垂直渐近线所在位置。

2. **值域/关键水平边界**
   - 有明确上下界的函数，例如 `asin(x)` 的 `±π/2`；
   - 函数在可视范围内的最高/最低水平线。

3. **特殊点**
   - 与 x 轴交点；
   - y 轴截距；
   - 局部极大/极小；
   - 周期函数的起点/峰值（仅在能提升理解时）。

4. **不要为了填满画面而标注**
   - 没有明确含义的普通点；
   - 任意采样点；
   - 用户没要求、且不影响读图的辅助线；
   - 与曲线重叠、会被遮住的位置。

## 给出方案，不直接加

当用户没有指定标注时，最多给 2–3 个方案，用询问框让用户选：

```text
A. 极简（推荐）
   只标定义域/值域边界，最多 2–4 个标签

B. 关键点
   在 A 的基础上，加零点、截距或极值，最多 6 个标签

C. 完整
   只在你确实需要时提供：边界 + 特殊点 + 必要的渐近线说明
```

渐近线现在可以用 `mathplot.asymptotes` 画灰色虚线并加 `y = 1` 之类的文字；仍必须先被用户选中，未选不画。`

询问框文案示例：

> 这张图要标到什么程度？
>
> - 极简：只标定义域/值域边界（推荐）
> - 关键点：再加零点/截距/极值
> - 完整：再加必要渐近线和范围说明
> - 不标注：只保留坐标轴

推荐项放在第一位；没有足够候选时，直接把“不标注”作为推荐。

## 生成约束

- 默认标签颜色 `#8E8E8E`；只有用户明确要求或确实需要强调时才用 `#36B59D`；
- 未选择渐近线时，不自动画虚线；
- 用户选“极简”后，不能偷偷补零点/极值；
- 用户选“不标注”后，只保留轴和用户点名标签；
- 同一张图标注数量保持少，优先保留最影响理解的 2–4 个；
- 如果函数在视域内没有有效候选，明确说“没有值得添加的标注”，不要凑数；
- 标准 schema 不够用时，先走 `overlay` 补少量圆点/文字/线段；仍不够才用受审 SVG 兜底，不能静默绕过 CLI。

## 示例

`asin(x)`：

```text
A 极简：x = ±1，y = ±π/2
B 关键点：A + 原点截距
C 完整：B + 端点说明
```

`sin(x)`：

```text
A 极简：可不标，或只标一个周期端点
B 关键点：零点 + 峰值
C 完整：仅在讲解周期性时补充更多
```

`1/x`：

```text
A 极简：不画渐近线，不标大量刻度
B 关键点：只标 x = 0 这个无定义位置
C 完整：用户明确要求时再加渐近线说明
```
