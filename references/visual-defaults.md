# 默认视觉规则

用户没有另行指定时，新生成的函数图/示意图统一使用这套视觉：

## 颜色

```text
背景：透明
中性内容（坐标轴、刻度、普通标签、辅助线）：#8E8E8E
关键内容（主曲线、主标题、重点标记）：#36B59D
```

原则：

- `#36B59D` 只给关键内容，少量使用；
- 不把整张图铺成绿色；
- 不用纯黑作为默认中性色；
- 同一张图不要出现第二套强调色。

## 布局

- 默认输出透明 PNG，便于放在白色或深色卡片上；
- 需要白底时显式指定 `"background": "#FFFFFF"`；
- 坐标文字只画用户指定的标签，不自动补全整排刻度；
- 坐标图只要原点在视域内，必须画灰色实心圆点并标 `O`；原点不在视域内不画；`O` 标签默认在原点右下方，并避开曲线与坐标轴线；`x` 轴名在轴下方右侧；`0` 标签与 O 冲突时优先保留 O；
- 线宽、字号、箭头等按图表需要设置，但颜色遵循上面的层级。

## 例外

- 锁定表格样式（`table`、`comparison`、`sales`）保留各自定义，不强行改成透明/灰绿；
- 用户提供的原图、扫描图保持原样，不自动改色；
- 化学结构由 RDKit 生成，默认保留其结构配色；需要主题化时单独说明；
- 用户明确指定颜色时，以用户指定为准。

## 当前实现

- `canvas.py mathplot` 已把透明底、`#8E8E8E` 中性色、`#36B59D` 关键色作为默认；
- 其他绘图路线在生成新图时按本规则执行，但不能自动改写已有 SVG/图片的内容颜色。
